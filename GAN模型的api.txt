api_name: /process_image
copy
import { Client } from "@gradio/client";

const response_0 = await fetch("https://raw.githubusercontent.com/gradio-app/gradio/main/test/test_files/bus.png");
const exampleImage = await response_0.blob();
						
const response_1 = await fetch("https://raw.githubusercontent.com/gradio-app/gradio/main/test/test_files/bus.png");
const exampleImage = await response_1.blob();
						
const client = await Client.connect("http://fortunefreedom.top:9091/");
const result = await client.predict("/process_image", { 
				input_image: exampleImage, 
				input_mask: exampleImage, 		
		slider_1: 0, 		
		slider_2: 0, 		
		radio: "人脸修复(基于FFHQ[7w张图]--最优)", 
});

console.log(result.data);

The input value that is provided in the "待修复的带划痕或者破损图像" Image component.

input_mask Blob | File | Buffer Required

The input value that is provided in the "表示划痕与破损位置的Mask掩膜" Image component.

slider_1 number Default: 0.5

The input value that is provided in the "设置截断值psi (0-1)" Slider component.

slider_2 number Default: 2

The input value that is provided in the "设置噪声值noise (0-9)" Slider component.

The input value that is provided in the "修补模型选择" Radio component.
